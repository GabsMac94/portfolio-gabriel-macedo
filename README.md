# Portfólio real — Gabriel Macedo

Landing page estática, responsiva e pronta para edição no Visual Studio Code.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `styles.css`: cores, tipografia, layout, responsividade e animações
- `main.js`: menu, animações no scroll e contadores
- `assets/images/Destinos/`: fotografias pessoais organizadas por aventura

## Como abrir

1. Extraia a pasta, caso tenha baixado um arquivo ZIP.
2. No Visual Studio Code, acesse **Arquivo > Abrir Pasta** e selecione `portfolio-gabriel-macedo`.
3. Abra `index.html` para editar textos e links.
4. Para visualizar, dê dois cliques no `index.html` ou use a extensão **Live Server** no VS Code.

## Personalização rápida

As aventuras atuais são Sistema Funicular, Pico do Lopo, Lagoa Esmeralda e Chapada Diamantina. A pasta da Chapada ainda está vazia e a página indica isso de forma transparente.

Para acrescentar as fotos da Chapada, coloque os arquivos em `assets/images/Destinos/Chapada-Diamantina/` e atualize o card correspondente no `index.html`.

O projeto não publica números, datas, redes sociais ou contatos provisórios.

As cores principais ficam no começo de `styles.css`, dentro de `:root`.
